# L'Almanacco del giorno dopo — contenuti

Contenuti dell'app Android *L'Almanacco del giorno dopo*.

- `contenuti.json` — il pacchetto che l'app scarica una volta a settimana. Se il campo `versione` è più recente di quello incluso nell'APK, l'app aggiorna da sola le pagine.
- `sorgenti/` — le schede giorno per giorno (`giorni/MM-GG.json`), la Smorfia, le feste mobili e lo schema (`SCHEMA.md`), leggibili e verificabili.

Fonti: Wikipedia e Wikimedia Commons, Wikiquote, Library of Congress.
